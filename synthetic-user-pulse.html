Headline. The AI is the part that works — a correct sequence diagram with the failure branch in ~10 s, honest credit accounting, a follow-up question in the right place. Everything around it makes the AI look like it failed: a marketing hero box that silently eats input, a "New diagram" button dead for 3 s, and an AI edit that lands in chat behind a button called Edit while the canvas doesn't move. Every persona described the product with a word like flaky, unfinished or untrustworthy; none would start the trial.

Escalate today: SSO login shows 62 successes vs 6,551 failures in 28 days. Either enterprise SSO is broken or the failure event over-fires — and the data can't tell you which.

Method & caveats

How to read this

One real trace of the production product was captured in a browser (screens, copy, DOM, console, network), then replayed to each of the six persona agents in isolation so all six judged an identical flow. Quantitative auth figures come from Mixpanel EU. Synthetic personas are a fast directional pass anchored in real customer quotes — the reliable signal is friction that recurs across several personas, not any single verdict. Confirm the recurring seams with live users.

To make the biweekly run unattended: the test needs a way past Cloudflare Turnstile — a flagged test account/domain, or a staging URL on the always-pass sitekey. Without it every run needs a human to sign in.
